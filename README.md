## ✨ Features

- 🤖 AI-powered study note summarization
- 🧠 AI-generated flashcards
- 📄 Upload PDF notes
- 📷 Scan handwritten notes
- ⚡ Powered by Google Gemini API
- 🎨 Built with Jetpack Compose
- 🌙 Modern dark UI

---

## 🛠 Tech Stack

- Kotlin
- Jetpack Compose
- MVVM Architecture
- Coroutines
- StateFlow
- Material 3
- Google Gemini API

---

## 🚀 Getting Started

```bash
git clone https://github.com/NisargBathwar/StudyAI.git
```

1. Open the project in Android Studio.
2. Add your Gemini API key.
3. Build and run the application.
